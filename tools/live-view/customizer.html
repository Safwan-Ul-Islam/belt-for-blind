How to use · ব্যবহার

Move: কম্পোনেন্ট ধরে টানুন। বেল্টে থাকলে চারপাশে ঘুরবে।

Orbit: ফাঁকা জায়গায় টেনে ঘোরান; scroll দিয়ে zoom।

Wire: একটি পিন, তারপর আরেকটি পিনে ক্লিক করুন। অথবা পাশের connection form ব্যবহার করুন।

তার বেছে নিলে কমলা handle টেনে বাঁক বদলাতে পারবেন। Esc চাপলে নির্বাচন বাতিল।

Position ও rotation ঘরে সংখ্যাও লিখতে পারবেন। Delete দিয়ে নির্বাচিত কম্পোনেন্ট বা তার মুছুন।
